## 🎯 Project Objectives

- Analyze overall tournament player statistics across metrics like total goals, assists, playing minutes, ratings, and top speed.
- Track top-performing goal scorers and evaluate player ratings across teams.
- Examine player demographic insights by nationality and geographical distribution.
- Evaluate team and individual performances across different tournament stages.

---

## 🛠️ Tools & Technologies Used

- **Business Intelligence:** Power BI (DAX, Power Query, Data Modeling)
- **Visuals & Analytics:** Custom KPIs, Scatter Plots, Map Visualizations, Bar Charts, Donut Charts
- **Data Source:** FIFA World Cup 2026 Dataset (`.csv`)
- **Design:** Modern Dark Sports Theme UI

---

### 📈 Core Visualizations & Breakdown

1. **Top 10 Goal Scorers:** Horizontal bar chart displaying top goal-scoring players.
2. **Player Rating Distribution:** Column chart analyzing rating spreads across players.
3. **Goals vs. Assists Analysis:** Interactive scatter plot comparing goal scoring against assist contributions by team.
4. **Players by Nationality & Global Distribution:** Donut chart paired with a map visual tracking global player representation.
5. **Team Performance Analysis:** Performance comparison across national teams (e.g., Japan, Austria, Cameroon, Iran, Netherlands).
6. **Tournament Stage Breakdown:** Distribution analysis covering matches in the Group Stage, Quarter Finals, and Finals.

---

## 🔍 Interactive Slicers & Filters

Filter the dashboard dynamically using built-in slicers:
* **Team** (e.g., Algeria, Argentina, Australia)
* **Nationality** (e.g., Algerian, American, Argentine)
* **Tournament Stage** (e.g., Final, Group Stage, Quarter Finals)
